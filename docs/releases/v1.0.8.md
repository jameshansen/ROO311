## What's changed

### Fixed

- **HostLink turns no event on for the whole machine.** HostLink asked for the host's pointer through EventV with the VSync event on, and that event reached every game's own event handler. Pipe Mania stopped with an address exception on one it never asked for. HostLink now asks every centisecond from TickerV, and only a pointer move goes into SVC mode for the callback that makes it. HostLink is version 1.04.

### Documentation

- The README's HostLink section says how the pointer is asked for.

The support pack, `toolbox.zip`, is the same as v1.0.6's.
