## What's changed

### Fixes

- The keyboard keeps working when a game unplugs the InternationalKeyboard module to free memory. The UK keyboard handler is part of the kernel again, as in RISC OS 3.11, and StarTrader now runs.
- The processor vectors at `&00` to `&1C` are branches again, as in RISC OS 3.11. Krisalis's music module finds the IRQ handler by decoding the branch at `&18`, and SWIV, SWIV BUZZ and Nebulus now run.
- ROO311 reports RISC OS 3.11's version numbers, with `OS_Byte 129` returning `&A4` and UtilityModule's help string giving 3.11. Raw Power and Sensible Soccer took their Risc PC paths when they found 3.60 and now match RISC OS 3.11, and Drifter no longer asks for the monitor type.
- Shrinking the font cache moves whatever FontManager can give up and reports no error. FontManager keeps 32K while the outline font desktop has fonts claimed, so Pandora's Box, The Legend of the Lost Temple and Carnage Inc, which empty the font cache to make room, stopped with "Memory cannot be moved". All three now run.
- The start-up banner's sprites sit in the system sprite area while the banner shows, and the module area has no gap after start-up. Saloon Cars's copy protection module writes past its own end, and in the 32K gap the banner left it damaged the next module and hung the machine. It now behaves as on RISC OS 3.11.

### Documentation

- 106 of the 127 JASPP games in the README's table reach the same screen as on RISC OS 3.11, up from 97. 3 don't run yet and 18 couldn't be judged. A new column says how each game starts.
- A new README section, Changes to the sources, lists every change made to the imported sources and the reason for it.
- Each release's notes list what it changed, with a short install guide.

## Known issues

- Grievous Bodily 'ARM, Tactic and Zool run on RISC OS 3.11 but not on ROO311 yet.
- MAME's A5000 stops while drawing the start-up banner.
- Red Squirrel shows no mouse pointer.
