## What's changed

### New

- A support pack, `toolbox.zip`, published beside the ROM and built from RISC OS Open's sources by `sh build.sh support`. It has the nested Window Manager 4.01, built for RISC OS 3.1, for an extension ROM, where it takes the ROM's place at power on; Toolbox 1.47 with its Window, Menu, Iconbar, ProgInfo, SaveAs, Scale and DCS modules, and CallASWI, for `!System`; and `!System` and `!Scrap` themselves. With it, release 3.21 of Star Fighter 3000 runs on ROO311.
- HostLink 1.01 reports an error box opening or closing and a task starting in the desktop, as Host_Event 4 and 5, from `Service_WimpReportError` and the Wimp's `Message_TaskInitialise`.

### Documentation

- The README has a Support pack section, and its HostLink section lists the new events.

## Known issues

- Grievous Bodily 'ARM, Tactic and Zool run on RISC OS 3.11 but not on ROO311 yet.
- MAME's A5000 stops while drawing the start-up banner.
- Red Squirrel shows no mouse pointer.
