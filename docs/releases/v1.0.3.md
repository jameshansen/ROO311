## What's changed

### Fixes

- Sound plays at the sample period a program sets. SoundDMA stored the divisor it had just used, 6, as the VIDC's sound frequency, so every sound played at 6 microseconds a byte: the desktop's channel came out 8 times too fast and Lemmings' music 2.67 times. The desktop now gets its 100 sound buffer interrupts a second.
- An A5000's 82C711 is found at start-up and ADFS uses its floppy controller. The kernel's test stored 0 in the serial port's scratch register where its comment says &AA, so an 82C711 that moves its serial port failed the test and ADFS reported "Disc drive not known". Botkiller 2 and Speedball 2 [RPC], which come on 1.6MB discs, now load, and 1.6MB and 800K discs format, write and verify.

### New

- HostLink, a module for emulators. Four SWIs in the chunk ArcEm answers itself let an emulator start an application, click an icon bar icon, move the pointer and hear about each change of screen mode. On a machine where nothing answers them it does nothing. The ROM now has 71 modules.

### Documentation

- The README lists the SoundDMA and 82C711 faults under Faults in the published source, and a new section describes HostLink and its SWIs.

## Known issues

- Grievous Bodily 'ARM, Tactic and Zool run on RISC OS 3.11 but not on ROO311 yet.
- MAME's A5000 stops while drawing the start-up banner.
- Red Squirrel shows no mouse pointer.
