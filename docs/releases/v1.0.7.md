## What's changed

### Fixed

- **The games modes are 1280 by 1920 OS units.** Modes 48 and 49, 320 by 480, are 4 OS units to a pixel down the screen as well as across, where they were 2 down. Games written for RISC OS 3.1 work out the pointer's place with 4, and in Star Fighter 3000 3.21's menus every click landed below the pointer, so clicking Play Game pressed Quit Menu.

### New

- **HostLink gives each new mode's eigen factors.** The mode change event has the mode's XEigFactor and YEigFactor in R2 and R3, so an emulator can turn pixels into OS units in any mode. HostLink is version 1.03.

### Documentation

- The README's HostLink section describes the event's new registers, and its list of changes to the sources has the games modes.

The support pack, `toolbox.zip`, is the same as v1.0.6's.
