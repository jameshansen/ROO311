## What's changed

### Fixes

- The kernel now reads the CMOS RAM on MAME's A5000. After checking an I2C acknowledge it took the clock and data lines low in one write, which MAME's clock chip read as a new start, so every setting read back as &FF and the machine stopped at the supervisor prompt. The clock line now goes low before the data line.
- ADFS now starts on a floppy controller that refuses the FIFO command. It sent the 82C711 a command meant for the Risc PC's floppy controller, and when MAME's controller refused it, ADFS's error path jumped to address 0. The FIFO is now left off, and floppy reads and writes work as before in Arculator.

With both fixes, MAME's A5000 gets as far as the desktop.

### Documentation

- The README lists the 127 JASPP games that ran on RISC OS 3.11 and how each one runs on ROO311. 97 reach the same screen as on RISC OS 3.11, 1 starts with a difference, 13 don't run yet and 16 couldn't be judged.
- A Memory section gives the memory left for applications from 512K to 4MB, beside RISC OS 3.11's figures.
- The README says how far ArcEm, MAME and Red Squirrel get, and how ArcEm takes the image.
- A new section sets out how the commercial ROMs were used during development.

## Known issues

- 13 JASPP games that run on RISC OS 3.11 don't run on ROO311 yet. The README's JASPP games section lists them.
- MAME's A5000 stops while drawing the start-up banner.
- Red Squirrel shows no mouse pointer.
