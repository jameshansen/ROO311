## What's changed

### New

- The support pack, `toolbox.zip`, has a `!Boot` with a `Choices` folder. Booting it sets `Choices$Path` and `Choices$Write`, as Acorn's Universal !Boot did for RISC OS 3.1, so programs can read and save their choices. Puzzle, which stopped with "Error reading user choices" where there was no `Choices:` path, runs with it.

### Documentation

- The README's Support pack section lists `!Boot`.

The ROM is the same as v1.0.4's.

## Known issues

- Grievous Bodily 'ARM, Tactic and Zool run on RISC OS 3.11 but not on ROO311 yet.
- MAME's A5000 stops while drawing the start-up banner.
