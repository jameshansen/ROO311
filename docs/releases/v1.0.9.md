## What's changed

### Fixed

- **A floppy's boot file gets the banner's memory back.** When Shift boots a floppy, the Desktop module leaves straight away so the disc's boot file can run, and it now gives back the banner's sprite space, its messages file and its workspace first, as it does when it closes. The system sprite area was left grown and full, so a game that loads sprites into it from its boot file couldn't: Chocks Away Compendium stopped with "Not enough memory in sprite area". The module area also has the Desktop's 1K of workspace back.

### Documentation

- The README's list of changes to the sources has this one.

The support pack, `toolbox.zip`, is the same as v1.0.6's.
