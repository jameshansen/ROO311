## What's changed

### Added

- **HostLink reports a task that stops.** HostLink passes on the Wimp's `Message_TaskCloseDown` as event 7, with the task's handle, as it passes on `Message_TaskInitialise` as event 5. An emulator can tell when a game that goes back to the desktop between games has quit, as E-Type II does after each race. HostLink is version 1.05.

### Documentation

- The README's HostLink section lists event 7.

The support pack, `toolbox.zip`, is the same as v1.0.6's.
