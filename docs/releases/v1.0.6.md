## What's changed

### New

- **HostLink reports where the windows on the screen are.** A sixth event gives the outline of each window, borders and all, whenever they change, looked at five times a second. The windows are found by going up the window stack from the icon bar, and a backdrop window such as the desktop's own is left out. An emulator can use it to show just a game's windows, for a game that plays in the desktop. HostLink is version 1.02.

### Documentation

- The README's HostLink section describes the new event and how the windows are found.

The support pack, `toolbox.zip`, is the same as v1.0.5's.
